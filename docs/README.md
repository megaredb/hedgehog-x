# Документация Hedgehog X

Комплект документов описывает **текущее поведение кода** репозитория `hedgehog-x`.
Единственный источник истины — код; документы — его карта и объяснение. Если код и
документ расходятся, прав код, а документ нужно обновить в той же правке.

> Проверено 2026-11-27 на HEAD `ff3f769`. Коммит и дата полезны
> только как ориентир: перед выводами о поведении проверяйте соответствующий
> файл кода.

## Принципы

1. **Только текущее состояние.** Здесь нет истории изменений и списков
   «было/стало». Документ отвечает на вопрос «как система работает сейчас».
2. **Пути к коду.** Ключевые утверждения сопровождаются путём к файлу; где
   полезно — номером строки.
3. **Один факт — одно место.** `AGENTS.md` содержит правила и алгоритмы работы,
   `docs/PROJECT_MAP.md` — где что лежит, `docs/ARCHITECTURE.md` — как это работает,
   `docs/DOMAIN.md` — что означают сущности, `docs/OPERATIONS.md` — как запускать и
   деплоить, `docs/TESTING.md` — как проверять.
4. **Никаких обещаний.** Если в коде нет функциональности, документ говорит «нет»,
   а не «планируется».
5. **Русский язык.** Тексты интерфейса и документации — русские; идентификаторы кода —
   английские.

## Как поддерживать

- Меняете схему БД, API-контракт, offline-поток, плеер, деплой — обновите
  `PROJECT_MAP.md`, `ARCHITECTURE.md` и (если затронуты правила) `AGENTS.md`.
- Меняете набор тестов или CI — обновите `TESTING.md`.
- Не создавайте второй источник истины и не дублируйте длинные разделы между файлами.
- Все относительные ссылки проверяйте: они должны вести на существующие файлы.
